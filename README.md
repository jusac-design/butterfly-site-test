# Butterfly website (butterflyapp.co.uk)

The public landing page for Butterfly. A single static page, published with GitHub Pages.

- `index.html`: the whole page (styles and scripts inline).
- `assets/`: the butterfly, Amy's photo and the share image.
- `CNAME`: the custom domain, `butterflyapp.co.uk`.

This repository is only the website. The Butterfly app lives in its own repositories and is not changed from here.
"Start your free 30 days" links to the app at https://jusac-design.github.io/butterfly/ until the app moves to its own address.

Design notes and wording decisions: `landing-page/4_DESIGN_DIRECTION.md` in the Butterfly project folder.
